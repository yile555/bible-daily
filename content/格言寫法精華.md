# 格言寫法精華（2026-11-16 整理）

來源：中文修辭學（香港、台灣國語文教材的修辭格整理）、《菜根譚》《佛光菜根譚》的修辭研究、英文格言與箴言寫作資料（aphorism / proverb、antithesis、chiasmus、parallelism）。只學結構與思路，用語一律繁體、台灣說法。

## 〇、主要寫法：整棵聖誕樹，只換飾品（2026-11-16 他定）
找一句本來就通順好記的勵志、祝福、鼓勵的話（例：oxxostudio.tw 的「鼓勵的話」「勵志語錄」「名人格言」），整句的語感、節奏、用字搭配都保留，只把關鍵的幾個字和方向換掉，讓它接上當天的經節和小品、指向神。像生日祝福改成守主日、逾越節、棕樹節用。
- 不是只拿骨架自己重填（那樣常像人皮裡裝狗骨頭，搭不起來）。
- 也不是硬放：情境不同時，找語氣相近的那一句，再換字、換方向。
- 樹的來源不用設限（2026-11-17 他定）：勵志語錄、名人格言、《道德經》、《增廣賢文》、《菜根譚》、俗語、麵店小吃店牆上的語錄都可以。出處不是基督教也沒關係，多半是勸人向善、引人省思；萬物都是神造的，本該拿來讚美神、領人歸主、使人更像基督。不要過度嚴謹（不要像法利賽人）。
- 例：成功者不是從不失敗，而是從不放棄 → 勇敢者不是從不發抖，而是從不後退。以誠感人者，人亦誠而應 → 以柔答人者，人亦柔而應。

## 一、好格言的三個條件
1. 一句只有一個新意。老生常談換個說法還是老生常談；要讓人「咦」一下。
2. 用一樣具體的東西把道理撐起來（比喻、借物）。
3. 有節奏，唸得順、記得住（對偶、押韻、數字）。

## 二、工具箱（輪著用，不要每句同一招）
| 手法 | 做法 | 例 |
|---|---|---|
| 對偶 | 前後字數、結構相同，意思相對或相承 | 謀算在人，成事在耶和華 |
| 對比／映襯 | 把相反的兩件事並排 | 罵在嘴上，疼在碗裡 |
| 回環 | 前後兩半詞語倒過來 | 我忘了祂，祂沒忘我 |
| 頂真 | 前一句的尾巴當後一句的頭 | 抄著抄著看見了，看見了就忘不了 |
| 層遞 | 一層比一層深或大 | 話軟一分，火退三尺 |
| 悖論 | 表面矛盾、細想是真的 | 手鬆開了，才拿得住 |
| 否定肯定 | 「不是……是……」把誤會翻過來 | 勇敢不是不怕，是怕了還站著 |
| 反問 | 用問句代替結論，讓人自己答 | 人心再硬，硬得過神的手嗎？ |
| 借代 | 用一樣東西代表一個人或身分 | 掃把養大的孩子，抬得起頭 |
| 仿擬 | 借大家熟的俗語、成語換字 | 家暖三代，非一日之功 |
| 用典＝以經解經 | 借別處經文的畫面，用自己的話 | 九十九個在，還找那一個 |
| 數字 | 用數字造成對比或份量 | 拆家一瞬間，建家一輩子 |
| 押韻 | 兩半句尾字同韻 | 酒越喝越糊塗，愛越給越清楚 |

## 三、寫的順序
1. 先找經節和當天小品重疊的那一點（同一件事）。
2. 從小品裡挑一樣具體的東西或動作。
3. 挑一個手法把它壓成一句，唸出聲，絆住就改。
4. 檢查：有沒有新意？是不是在解釋？沒讀故事的人看不看得懂？

## 四、避開
- 「……，是……」「……常常……」連續用成習慣，變成說明文。
- 冒號句「主張：解釋」。
- 留白過頭（「三個字」那種謎語）。
- 硬裝文雅、疊形容詞、混兩個比喻。
